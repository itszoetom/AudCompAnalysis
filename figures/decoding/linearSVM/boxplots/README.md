# SVM Boxplots

Per-subregion boxplots of mean pairwise linear SVM accuracy, one figure per sound type. Pairwise subregion comparisons use Mann-Whitney U with Bonferroni correction.

- `linearSVM_{PT,AM,naturalSound,speech}_region_boxplots.png` — accuracy across subregions and windows.
- `linearSVM_naturalSound_within_between_boxplots.png` — within-category vs. between-category split for natural sounds.
